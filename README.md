# E-Commerce and Inventory Management System

A console-based E-Commerce and Inventory Management System developed using **Core Java**. The project demonstrates object-oriented programming concepts, product management, inventory control, customer operations, order processing, and file handling.

## Project Overview

The application is designed to simulate the basic operations of an e-commerce platform. It provides separate functionalities for administrators and customers.

Administrators can manage products and inventory, while customers can browse products, manage shopping carts, and place orders.

The project is being developed incrementally as part of an academic Java programming project.

## Planned Features

### Admin Module
- Add, update, remove, and search products.
- Manage product inventory.
- Monitor low-stock products.
- View and manage customer orders.
- Update order statuses.
- Generate basic sales reports.

### Customer Module
- Customer registration and login.
- Browse and search products.
- Add, remove, and update cart items.
- Place orders.
- Simulated payment processing.
- View order history.
- Cancel eligible orders.

### Product Categories
- Electronics
- Clothing
- Books

Each category has its own attributes and product details.

## How to Run

1. Install JDK (Java Development Kit).
2. Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/ECommerceSystem.git
```

3. Open the project folder in VS Code.
4. Make sure the Java Extension Pack is installed.
5. Open `src/main/Main.java`.
6. Run the application using **Run Java**.
